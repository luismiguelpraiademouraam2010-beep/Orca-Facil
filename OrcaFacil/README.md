# OrçaFácil
Sistema acadêmico para organizar clientes, serviços e orçamentos.

## Tecnologias
HTML, CSS, JavaScript, Python (Flask) e MySQL.

## Preparação
1. Execute `database/banco_projeto.sql` no MySQL.
2. Copie `.env.example` para `.env` e configure usuário e senha do MySQL.
3. No terminal, entre em `backend`.
4. Execute `pip install -r requirements.txt`.
5. Execute `python app.py`.
6. Abra `frontend/index.html` no navegador.

Não envie o arquivo `.env` ao GitHub. Ele contém configurações locais.
